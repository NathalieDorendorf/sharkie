Game Instructions

Use the arrow keys or WASD to move your character.

Press Space to attack with your fin and F to throw objects.

About the Game

Sharkie is an 2D underwater adventure game where you control a shark navigating through various levels, collecting coins and avoiding enemies.

Developed by Nathalie Dorendorf, this game showcases basic game mechanics and object-oriented programming principles.
